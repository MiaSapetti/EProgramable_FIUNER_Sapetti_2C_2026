Control de Display BCD de 7 Segmentos Multiplexado

Descripción General

Este programa permite descomponer un número entero en sus dígitos BCD (Binary-Coded Decimal) y mostrarlos dinámicamente en un display de 7 segmentos de 3 dígitos mediante un bus de datos de 4 bits y un bus de selección de dígitos (multiplexado).

Conexión de Hardware

Componente Bus / Función ESP32 (GPIO)
Bus BCD Bit 0 (b0) GPIO_20
Bus BCD Bit 1 (b1) GPIO_21
Bus BCD Bit 2 (b2) GPIO_22
Bus BCD Bit 3 (b3) GPIO_23
Selector Dígito 1 GPIO_19
Selector Dígito 2 GPIO_18
Selector Dígito 3 GPIO_9
